# Fractal Art Explorer v4.7.1 — Artistic Refinement

Questa versione parte dalla **4.7 Stable** e introduce tre miglioramenti mirati:

1. **Zoom più intelligente**: il motore si ricorda il punto in cui hai zoomato e concentra più dettaglio iniziale in quella zona nei passaggi rapidi, accelerando la sensazione di messa a fuoco.
2. **Colori più cinematografici**: gradazione più filmica con contrasto leggermente più controllato, neri più profondi e sfumature più ricche.
3. **Transizione tra opere più morbida**: quando cambi opera, la precedente rimane come base e la nuova emerge con una rifinitura più lenta e raffinata.

## Resta invariato

- 123 opere
- 71 formule
- 32 palette
- deep zoom fino a 1024 bit
- ciclo colori
- fullscreen / modalità immersiva
- rendering progressivo a strati
